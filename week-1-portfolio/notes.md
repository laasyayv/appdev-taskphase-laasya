**HTML (Hyper Text Markup Language)**

* It is used to structure the content of a webpage (backbone of websites).
* It uses tags (like h1, a, p...(enclosed in angualr brackets)) to organize contents and the text inside the angular brackets is case-insensitive.
* <meta> tag to specify the character encoding, ensuring proper rendering \[metadata].
* File extension .html
* <a> tag is used for creating hyperlinks.
* CSS (Cascading Style Sheets) is used for styling/designing the webpage.
